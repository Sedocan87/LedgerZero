# Comparison: Mint vs. LedgerZero

| Feature | Mint (Discontinued) | LedgerZero |
| :--- | :--- | :--- |
| **Cost** | Free (Ad-supported) | One-time purchase ($49.99 - $79.99) |
| **Platform** | Web, iOS, Android | iOS, Android, macOS, Windows, Linux |
| **Data Storage** | Cloud (Intuit Servers) | Local (Your Device + Your Cloud) |
| **Sync** | Automatic (Plaid/Yodlee) | File-based Sync (Google Drive, iCloud) |
| **Budgeting Style** | Expense Tracking / Trends | Zero-Based Envelope Budgeting |
| **Customization** | Limited Categories | Fully Custom Categories & Groups |
| **Privacy** | Data used for ads/marketing | Private (E2E Encrypted) |
| **Offline Access** | No | Full Offline Functionality |
| **Ads** | Yes, frequent | None, ever |
| **Support** | Chat / Help Center | Email / Community / Docs |

## Why Switch?

1.  **Sovereignty**: You own your data. No one can shut down LedgerZero or sell your financial history.
2.  **Focus**: No ads cluttering your interface. Just your money.
3.  **Methodology**: Envelope budgeting is proactive (planning), while Mint was reactive (tracking). This helps you save more effectively.
4.  **Performance**: Native app performance, instant load times, no waiting for bank servers.

## Missing Features (vs. Mint)

*   **Auto-Sync**: LedgerZero does not connect directly to banks. You must enter transactions manually or import CSVs. This is a design choice for privacy and stability.
*   **Credit Score**: LedgerZero is a finance tool, not a credit monitoring service.
*   **Bill Negotiation**: We don't negotiate your bills or suggest credit cards.
