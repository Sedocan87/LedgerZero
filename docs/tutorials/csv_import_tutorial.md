# CSV Import Tutorial Script

**Title**: Importing Transactions from Your Bank into LedgerZero
**Duration**: 2-3 minutes
**Format**: Screen recording with voiceover

## 1. Introduction (0:00 - 0:30)
- **Visual**: Show the LedgerZero Home Screen.
- **Audio**: "Welcome to LedgerZero. In this tutorial, we will show you how to import your bank transactions using a CSV file. This allows you to bulk add transactions from your bank statement without manual entry."

## 2. Preparing the CSV (0:30 - 0:45)
- **Visual**: Show a bank website (generic) or a spreadsheet view of a CSV file.
- **Audio**: "First, log in to your bank's website and download your transaction history as a CSV file. Ensure the file includes columns for Date and Amount at a minimum."

## 3. Starting the Import (0:45 - 1:15)
- **Visual**: Navigate to Settings -> Import Transactions.
- **Audio**: "Open LedgerZero. Go to Settings, then tap 'Import CSV'. Select the account you want to import transactions into."

## 4. Mapping Columns (1:15 - 1:45)
- **Visual**: Show the file picker and then the Column Mapping screen.
- **Audio**: "Select your CSV file. Now, map the columns from your file to LedgerZero's fields. Match 'Date', 'Amount', and optionally 'Payee' or 'Memo'. Check the date format preview to ensure it matches your file."

## 5. Review and Import (1:45 - 2:30)
- **Visual**: Show the transaction preview list. Select/Deselect items. Tap 'Import'.
- **Audio**: "Review the transactions found in the file. Uncheck any you don't want to import. Tap 'Import' to finish. LedgerZero will automatically detect potential duplicates."

## 6. Conclusion (2:30 - 3:00)
- **Visual**: Show the updated Transaction List with new entries.
- **Audio**: "Your transactions are now imported. You can categorize them as needed. Thanks for using LedgerZero."
